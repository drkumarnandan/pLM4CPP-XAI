# Clean replacement of the old GitHub repository

Repository: `https://github.com/drkumarnandan/pLM4CPP-XAI`

## Delete the old repository
Only do this if you do not need the old commit history.

1. Open the old `pLM4CPP-XAI` repository.
2. Click **Settings**.
3. Scroll to **Danger Zone**.
4. Click **Delete this repository**.
5. Enter the repository name when GitHub asks for confirmation.
6. Confirm deletion.

## Recreate
1. Open `https://github.com/new`.
2. Repository name: `pLM4CPP-XAI`
3. Description: `Explainable protein language model framework for cell-penetrating peptide prediction and residue-level interpretation`
4. Choose **Public**.
5. Do NOT initialize it with README, .gitignore, or license.
6. Create the repository.
7. Click **uploading an existing file**.
8. Upload the CONTENTS inside this `pLM4CPP-XAI` folder, not the ZIP itself.
9. Commit message: `Initial public release of pLM4CPP-XAI`
10. Commit the upload.

After upload, open `notebooks/00_QUICKSTART_Predict_New_Sequences.ipynb`.
The README includes a one-click Colab badge for end users.
