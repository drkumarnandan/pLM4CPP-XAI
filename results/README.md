# Results

Generated tables, figures, model checkpoints, embeddings, and per-residue attribution
files are intentionally excluded from the GitHub package because they can be large.

The notebooks recreate the study directory structure and write outputs under:

- `03_embeddings/`
- `04_models/`
- `05_predictions/`
- `06_xai/`
- `07_results/`
- `08_checkpoints/`
- `09_logs/`

For archival publication, selected lightweight result tables can be added here or
deposited in Zenodo/Figshare and linked from the README.
